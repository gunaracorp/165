## 🕌 Apa itu 165 — What is 165

**Bahasa Indonesia.**
165 bukan sekadar situs web. It preserves the knowledge, sanad, and heritage of **TQN Qodiriah Naqsabandiyah** with source-first honesty, built to outlast trends.

## ⚖️ Enam Doktrin Institusional — Six Institutional Doctrines

| # | Doktrin (ID) | Doctrine (EN) |
|---|---|---|
| 1 | **Source-First** — tidak ada catatan tanpa sumber yang teridentifikasi | **Source-First** — no record without an identified source |
| 2 | **Bukti bergrade A–F** — setiap catatan membawa tingkat buktinya; F tampil sebagai ketidakpastian, bukan fakta | **Evidence graded A–F** — every record carries its evidence level; F is displayed as uncertainty, never as fact |
| 3 | **Status verifikasi jujur** — Verified · Documented · Traditional Account · Disputed · Unverified | **Honest verification statuses** — Verified · Documented · Traditional Account · Disputed · Unverified |
| 4 | **Pure-Append** — sejarah tidak pernah dihapus; koreksi menambah versi, audit, dan snapshot | **Pure-Append** — history is never deleted; corrections add versions, audit entries and snapshots |
| 5 | **Sanad Safety** — sanad hanya display-only; tidak pernah dikarang, digabung, diprediksi, atau dinilai legitimasinya; simpul yang belum terekam ditandai jujur `[ MATA BLOK ]` | **Sanad Safety** — display-only; never invented, merged, predicted, or ranked; unrecorded generations are marked honestly as `[ MATA BLOK ]` |
| 6 | **Identitas global** — setiap entitas punya ID kanonik (`165-PERSON-000002`, `165-SANAD-000001`, …) yang stabil lintas tampilan | **Global identity** — every entity carries a stable canonical ID (`165-PERSON-000002`, `165-SANAD-000001`, …) |

> **Aturan sejarah yang kritis:** "Do not make 165 look more authoritative than its evidence allows — make it more trustworthy than it needs to appear."

## 🧰 Teknologi — Tech Stack

| Lapis | Teknologi |
|---|---|
| Framework | **Next.js 16** (App Router, single-route SPA institusional) + **TypeScript 5** |
| UI | **Tailwind CSS 4** + shadcn/ui (New York) + Lucide; identitas v.4 "Emerald Radiance" (zamrud `oklch` + kuningan), font Nunito + serif display |

| i18n | Mesin i18n mandiri (`useSyncExternalStore`), kamus kurasi + kamus AI per-bahasa ter-code-split |
| AI | `z-ai-web-dev-sdk` (backend-only) — Tanya 165 & pipeline terjemahan, dengan larangan keras anti-fabrikasi (sanad, ijazah, kutipan) |

### Prasyarat & Menjalankan — Prerequisites & Running

```bash
# Bun (disarankan) — https://bun.sh
bun install

# basis data
bun run db:push          # push schema Prisma → SQLite
bun run sanad:seed       # restorasi 3 jalur sanad (additive, idempoten)
bun run dev              # http://localhost:3000
```
